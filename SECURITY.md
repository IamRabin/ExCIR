# Security Policy

## Supported Versions

ExCIR is an academic research repository under active development.

Security and maintenance updates are provided for the latest version of the code available on the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest `main` branch | ✅ |
| Older snapshots or archived versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability or a security-related issue in ExCIR, please report it privately rather than opening a public GitHub issue.

Please contact:

**Poushali Sengupta**  
Department of Informatics (IFI)  
University of Oslo (UiO), Norway  
Email: **poushals@ifi.uio.no**

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps required to reproduce it
- The affected file, component, or functionality
- Any potential security impact
- Relevant logs or supporting information, if available

Reports will be reviewed as soon as reasonably possible. If the issue is confirmed, appropriate corrective actions will be taken and the reporter may be contacted for additional information.

Please avoid publicly disclosing security vulnerabilities before they have been reviewed and addressed.
