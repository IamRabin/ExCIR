# Contributing to ExCIR

Thank you for your interest in contributing to **ExCIR (Explainable AI with Correlation-Impact Ratio)**.

ExCIR is developed and maintained as part of research on explainable and trustworthy artificial intelligence at the **Department of Informatics (IFI), University of Oslo (UiO), Norway**.

## How to Contribute

Contributions that improve the framework, implementation, documentation, reproducibility, or evaluation of ExCIR are welcome. These may include:

- Bug fixes and implementation improvements
- Documentation improvements
- Additional tests and reproducibility checks
- New datasets or benchmarking experiments
- Extensions of the ExCIR framework
- Integration with additional machine-learning or XAI methods

For substantial methodological changes or new extensions, please open an issue first to discuss the proposed contribution.

## Reporting Issues

If you encounter a bug, unexpected behavior, or reproducibility issue, please open a GitHub issue and provide:

- A clear description of the problem
- Steps required to reproduce it
- Relevant environment or dependency information
- Error messages or logs, where applicable

## Pull Requests

When submitting a pull request:

1. Clearly describe the purpose of the proposed change.
2. Keep changes focused and avoid unrelated modifications.
3. Ensure that existing functionality is preserved.
4. Add or update documentation where appropriate.
5. Include tests or reproducibility evidence for substantive changes.

## Research Contributions

Research extensions based on ExCIR are encouraged. Contributions introducing new algorithms, theoretical extensions, benchmarks, or substantial experimental components should clearly document how they extend the existing ExCIR framework.

Authorship on research publications is separate from software contribution and is determined according to the scientific contribution to the corresponding work.

## Citation

If you use ExCIR in academic research, please cite the corresponding ExCIR publication(s). See the repository `README.md` or `CITATION.cff` for the current citation information.

## Code of Conduct

Contributors are expected to communicate respectfully and constructively. Technical disagreement and critical scientific discussion are welcome when conducted professionally.
